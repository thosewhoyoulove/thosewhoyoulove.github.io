# 前端工程化速记

## 面试回答

> 工程化是用规范、工具和流程降低多人协作与长期交付的复杂度，不是工具名清单。开发要启动/HMR 与提交质量；构建要速度与产物体积/缓存；质量靠 lint、类型、测试、CI 前置；发布要环境隔离、可回滚；线上要监控闭环。Webpack 抓依赖图与 loader/plugin；Vite 抓开发 ESM 按需 + 生产 Rollup。优化先指标后配置。

**一句话总结：**

> 工程化=可重复交付系统；构建只是其中一层。

## 高频追问

### Webpack vs Vite？

Webpack：统一依赖图，生态与定制强，开发冷启动常更重。Vite：开发按需 ESM 快；生产仍打包（Rollup）。

### Loader vs Plugin？

Loader 转单模块；Plugin 扩生命周期。

### 为什么生产还要打包？

控请求、摇树、压缩、分割与缓存；裸 ESM 文件数通常过大。

### 优化如何证明？

构建耗时、主包体积、LCP、缓存命中、路由懒加载耗时。

### Tree Shaking 为何失效？

CJS、副作用、ESM 被提前转 CJS、`sideEffects` 标错。
