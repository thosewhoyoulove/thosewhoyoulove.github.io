# 面试总览

面向约 **3 年 Vue / React 前端**。按「能背、能追问」组织，不要按侧栏从第一页刷到最后一页。

## 怎么用

```text
复习路线 / 高频追问清单
  → 方向速记（短、可背）
  → 一篇专题深文（把口述稿讲透）
  → 项目 2 分钟口述
```

1. 时间紧：先打开 [复习路线](/md/面试准备/复习路线.md) 的 3 天冲刺，按表执行。
2. 查漏：打开 [高频追问清单](/md/面试准备/高频追问清单.md)，不会的再点进深文。
3. 项目：用 [项目表达模板](/md/面试准备/项目表达模板.md) 把经历压成 2 分钟 / 5 分钟版。

JS / 浏览器默背主链：闭包、this、原型链、防抖节流、Promise、事件循环、TS 建模、渲染 / 缓存 / 首屏、DOM 事件、本地存储。手写 Promise、V8 细节、call/apply 专文作加分，答稳 P0 再看。

## 三层内容怎么选

| 层级 | 作用 | 怎么用 |
| --- | --- | --- |
| 速记 | 提纲 + 关键词 + 链深文 | 考前默背主路径 |
| 专题深文 | 口述稿 + 原理 + 误区 + 追问 | 某个点答不深时精读一篇 |
| 索引 / 附录 | 考点索引、移出侧栏的加分文 | 只当目录，不要整本背 |
